# FutureLife

Un cruscotto personale per prendere decisioni migliori oggi, pensando agli effetti futuri.

## Perché

Nel 2026 il problema non è avere poche informazioni. È decidere cosa conta davvero.

FutureLife assegna una priorità alle attività usando due fattori semplici:

- **Impatto futuro**: quanto può migliorare la tua vita
- **Sforzo**: quanto costa farlo

## MVP

- priorità giornaliere
- obiettivi divisi per area della vita
- scadenze
- rapporto impatto/sforzo
- interfaccia Streamlit

## Roadmap

1. Diario delle decisioni
2. AI coach con memoria personale controllabile
3. Simulazione di scenari a 1, 5 e 10 anni
4. Integrazione calendario e attività
5. Dashboard salute, finanze e tempo
6. Privacy-first: dati esportabili e cancellabili
7. Automazioni e suggerimenti proattivi

## Avvio

```bash
pip install -r requirements.txt
streamlit run app.py
```
